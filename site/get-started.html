Get started

Pick the setup that matches how you want to listen. The first one takes about two minutes.

Downloads On one computer Phone and TV Always-on server With Docker Without Docker

Downloads

The current version is the latest release. The app updates itself after this.

WindowsInstaller LinuxAppImage, runs on most systems Debian and Ubuntu.deb package

There is also a portable Windows version that runs without installing. There is no macOS build yet.

Windows will warn you the first time. The app is not signed with a paid certificate yet, so Windows shows "Windows protected your PC". Click More info, then Run anyway.

On one computer

This is all most people need. Nothing else has to be installed.

  1. Install and open the app. On Linux with the AppImage, make the file executable first: right-click it, open Properties, and allow it to run as a program.
  2. Click "Choose your music folder" and pick the folder that holds your music. Subfolders are included.
  3. Wait for the scan. A few thousand songs take about a minute. Albums appear as they are found.

There is no sign-in in this setup. To use a different folder later, go to Settings and change the music folder there.

On your phone and TV too

The app on your computer can share its library with other devices on the same Wi-Fi or router. It works while the app is open.

  1. In the app, open Settings and find Other devices. Turn on Let other devices on my network connect. If Windows asks whether to allow network access, choose Allow.
  2. Under Users, add a name and password. This is what you sign in with on the other device.
  3. On the phone or TV, open a browser and enter the address the app shows. It looks like http://192.168.1.20:47821.
  4. Sign in with the name and password from step 2.

On a phone, use your browser's Add to Home Screen to get an app icon. The player keeps working with the screen locked.

An always-on server

Choose this if you want the library available when your computer is off, or reachable from outside your home. You run the server on a machine that stays on, and every device connects to it, including the desktop app.

With Docker

You need Docker. A ready-made image is published with every release, for regular PCs and for ARM machines such as a Raspberry Pi.

  1. Make a folder for it and download the setup file into it: 
    mkdir localhostmusic && cd localhostmusic
curl -O https://raw.githubusercontent.com/localhostmusic/localhostmusic/main/docker-compose.yml
  2. Open docker-compose.yml and change ./music to the folder that holds your music.
  3. Start it: 
    docker compose up -d
  4. Get the admin password, which is created and shown once on the first start: 
    docker compose logs localhostmusic
  5. Open http://localhost:8585 on that machine, or http://its-address:8585 from another device, and sign in as admin.

The server starts again by itself after a reboot.

Without Docker

You need Node.js 24 or newer and FFmpeg. These steps are for Linux and macOS. On Windows, the desktop app with sharing turned on is the simpler route.

git clone https://github.com/localhostmusic/localhostmusic.git
cd localhostmusic

# Build the player
cd web
npm ci
npm run build

# Build the server and give it the player
cd ../server
npm ci
npm run build
cp -r ../web/dist public

Then start it, with your own folders in place of the examples:

MUSIC_DIR=/path/to/your/music \
DATA_DIR=/path/to/a/folder/for/its/data \
node dist/index.js

The first start prints the admin password once. Open http://localhost:8585 and sign in as admin. Use the same Node.js version to install and to run; if you upgrade Node.js, run npm ci in server again.

Before opening a server to the internet: put it behind HTTPS with a reverse proxy, set TRUST_PROXY=1, and change the admin password. The docs have the details.
