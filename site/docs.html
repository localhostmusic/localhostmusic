Accounts

Each person gets their own account, with their own playlists, ratings, favourites and listening history. The music itself is shared.

The first account is the admin. Admins add people under Settings, Users. The desktop app used on one computer has a single account and signs you in by itself.

Signing in

A sign-in lasts 30 days on a device. Closing the app or the tab does not sign you out; only the Sign out button does.

  • Profile tiles. After you sign in once on a device, the sign-in page shows a tile with your name and picture. Click it and type only your password.
  • No password on a trusted device. Tick Don't ask for my password on this device when you sign in, or turn it on under Account, Password. Your tile then opens your account directly. Anyone using that device can do the same, so keep it for devices you trust.
  • Everyone listed. An admin can turn on Show all users on the sign-in page under Settings, Users, so people can pick their name on a new device. Leave it off if the server can be reached from the internet.

Passwords

Change yours under Account, Password. It signs your other devices out.

There is no email reset, because passwords live only on your server. If someone forgets theirs, an admin sets a new one under Settings, Users, Reset password, and the person changes it after signing in.

If the admin password itself is lost, start the server once with RESET_ADMIN_PASSWORD set to a new password of 8 or more characters, sign in, then remove that setting.

Your library

The app reads your files where they are and never moves them. It checks for new and removed files by itself every 15 minutes; admins can change how often under Settings, Library. If you just added something and don't want to wait, anyone can press Check for new music on the Account page.

Albums and artists come from the tags inside the files. If something is filed under the wrong artist or album, the tags are the place to look. Admins can fix tags from the app, which writes the change back to the file.

FLAC, MP3, AAC, Ogg, Opus and other common formats play as they are. For slower connections, each device can ask for a smaller converted stream under Account, Quality.

Lyrics

Open the player and turn on the Lyrics panel. Synced lyrics come from LRCLIB when it has them.

To time lyrics yourself, click the pencil in the player with the Lyrics panel open. Paste the words, one line each, press play, and tap as each line starts. You can nudge a line afterwards, and share the result back to LRCLIB if you like.

Phones

Open your server's address in the phone's browser and sign in. Then use Add to Home Screen (Share menu on iPhone, the browser menu on Android) to get an app icon that opens full screen.

Playback continues with the screen locked, with controls on the lock screen. Songs you download in the app stay available without a connection.

TVs

Any TV with a browser can open your server's address followed by /tv, for example http://192.168.1.20:8585/tv. That page is built for a remote control.

For Android TV there is a small app that wraps that page so the remote's arrows work properly. It is not in the downloads yet; for now it has to be built from the tv-app folder in the source.

Updates

The desktop app checks for a new version when it opens and offers it in a card with the list of changes. You can also check under Settings, Desktop app. See the changelog for what each version changed.

A server tells its admins when a newer version is out: a notification in the bell, and the list of changes under Settings, Server. It checks GitHub once a day and never installs anything by itself. You can turn the check off in the same place.

To update a Docker server, run this in the folder with your docker-compose.yml:

docker compose pull
docker compose up -d

It takes about a minute. Your library and accounts are kept, and the database updates itself on the first start of a new version. Phones, TVs and browsers need nothing: they load the player from the server.

For hands-off updates, Watchtower can pull new images and restart the container for you. Without Docker, run git pull and repeat the build steps from Get started.

Backups

Your music files are never changed unless you edit tags, so back them up however you already do. Everything else, including accounts, playlists, ratings and history, lives in one data folder:

SetupWhere the data is
Desktop app, Windows%APPDATA%\Localhost Music
Desktop app, Linux~/.config/Localhost Music
Dockerthe lhm-data volume
Without Dockerthe folder you set as DATA_DIR

Stop the app or server, copy that folder somewhere safe, and start it again. To restore, put the folder back.

Outside your home

To reach a server from outside your network, put it behind a reverse proxy that provides HTTPS, such as Caddy or nginx, and:

  • set TRUST_PROXY=1, so the sign-in limiter sees real addresses and cookies are marked secure;
  • use a strong admin password;
  • keep Show all users on the sign-in page turned off.

Album covers and artist photos can be fetched without signing in, so that lock screens and car displays can show them. Everything else needs an account.

Troubleshooting

My phone or TV can't reach the app on my computer

Check that Let other devices on my network connect is on, the app is open, and both devices are on the same network. On Windows, allow the app through the firewall when asked. The address can change when your router restarts; the app always shows the current one.

Songs are missing

Press Check for new music on the Account page, or Rescan library in Settings. Files the scanner could not read are listed under Settings, Library health with the reason.

The desktop app says the library stopped

The message includes the last lines of its log. The full log is server.log in the app's data folder, listed under Backups.

Something else

Open an issue on GitHub and say what you did, what happened, and which version you are on. The version is at the bottom of the sidebar.
