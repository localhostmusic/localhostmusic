# Contributing to Localhost Music

Thanks for helping. Bug reports, fixes and features are all welcome.

## Before you open a PR

- `cd server && npm test` and `cd web && npm test` pass.
- `cd web && npx tsc -b --noEmit` is clean.
- For anything bigger than a bug fix, open an issue first so we can agree on the shape.
